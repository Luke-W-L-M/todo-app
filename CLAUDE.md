## Stack

- Plain HTML, CSS and JavaScript. No framework.
- Data stored in `localStorage`.
- No build step, no package manager, no tests, no linter.

## Running the app

Open `index.html` in Chrome. No server needed.

To reset the app, clear the `todo-tasks` and `todo-theme` keys in DevTools → Application → Local Storage.


## Conventions

- One file per concern: `index.html`, `style.css`, `app.js`.
- Write in short sentences. One idea each.
- If anything is unclear, ask me as many questions as you think necessary before making assumptions.
- Once the plan is clear, summarise it and wait for me to type "approve".
- In dark mode, the letters and boxes must always have vibrant neon outlines.
- Whenever a change is complete, give me recommendations on where to work on next in bullet points ranked by priority.

## Do not

- Use `eval()`.
- Commit any secrets — no API keys, passwords, or tokens in the files.
- Push anything to Github without asking me and showing me what has changed since the last commit.
